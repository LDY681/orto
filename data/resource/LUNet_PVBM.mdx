LUNet is a novel deep learning architecture optimized for high-resolution A/V segmentation trainind on an new on-house DFI dataset with 240 crowd-sourced manual A/V segmentations.
The LUNet model features a double dilated convolutional block to widen the receptive field and reduce parameter count, alongside a high-resolution tail to refine segmentation details.
The release of the new datasets and the LUNet model can be found <a className="text-primary-400 underline" target="_blank" href="https://www.aimlab-technion.com/lirot-ai">[here]</a>.
<br/>
PVBM is a fully automated Vasculature BioMarker toolbox developed in Python by the same authors, based on DFI segmentations.
A total of 11 VBMs were implemented, including new algorithmic methods to estimate tortuosity and branching angles. 
The PVBM toolbox is made opensource under a GNU GPL 3 license and is available <a className="text-primary-400 underline" target="_blank" href="https://physiozoo.com/">[here]</a>.
