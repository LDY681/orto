LUNet and PVBM are tools enabling vessel segmentation and assessment, respectively.
LuNet is a deep learning model enabling segmentation of arterioles and venules in high-resolution fundus images.
The images segmented via LuNet can then be segmented using PVBM (A Python Vasculature Biomarker Toolbox), delivering 11 vascular metrics.
The LUNet can be found <a className="text-primary-400 underline" target="_blank" href="https://www.aimlab-technion.com/lirot-ai">[here]</a> and PVBM <a className="text-primary-400 underline" target="_blank" href="https://physiozoo.com/">[here]</a>.
