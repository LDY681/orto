This repository contains 28,943 Humphrey Visual Field (HVF) tests from 3,871 patients and 7,428 eyes.
This file contains sensitivity values, TD values, age, laterality (left or right eye) and gender when specified.
Sensitivity and TD values are stored both in long format (as a vector) and provided as an 8 x 9 matrix.
The latter is meant to preserve the original spatial organisation of the data, which is particularly useful in spatial-aware processing often employed in machine learning.
All visual field data are stored for the right eye.
The dataset is available on <a className="text-primary-400 underline" target="_blank" href="https://github.com/uw-biomedical-ml/uwhvf">Github</a> and described in the paper by Montesano G, et al.
UWHVF: A Real-world, open-source dataset of perimetry tests from the Humphrey Field Analyser at the University of Washington. Transl Vis Sci Technol. 2022 Jan 3;11(1):2, available <a className="text-primary-400 underline" target="_blank" href="https://tvst.arvojournals.org/article.aspx?articleid=2778219">[here]</a>.
