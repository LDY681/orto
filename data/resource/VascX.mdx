VascX is an open-source deep learning model for retinal vascular analysis from colour fundus images.
It enables segmentation of the vessel, the artery-vein, and the optic disc, as well as localisation of the fovea for colour fundus images.
The tool is described in Vargas Quiros J, et al. VascX Models: deep ensembles for retinal vascular analysis from color fundus images.
*Transl Vis Sci Technol.* 2025 Jul 1;14(7):19.
The model, weights and inference code are available on <a className="text-primary-400 underline" target="_blank" href="https://github.com/Eyened/rtnls_vascx_models">[GitHub]</a> and paper <a className="text-primary-400 underline" target="_blank" href="https://doi.org/10.1167/tvst.14.7.19">[here]</a>
