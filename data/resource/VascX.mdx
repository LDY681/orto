VascX presents and validates deep learning model ensembles (VascX) for vessel, artery-vein, optic disc segmentation, and fovea localization for color fundus images (CFIs).
Model weights and inference code are publicly available at <a className="text-primary-400 underline" target="_blank" href="https://github.com/Eyened/rtnls_vascx_models">[here]</a>.
