A Python software library that can co-register and analyse optoretinography (ORG) datasets, while also enabling process auditing, towards reproducible and repeatable analyses of ORG data.
The details can be found in a paper: Cooper RF, Gaffney M, Brennan BD, Rios N. ƒ(Cell): Software for Reproducible Analysis of Optoretinograms.
