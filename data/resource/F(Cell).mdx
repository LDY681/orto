A Python software library that can co-register and analyse optoretinography (ORG) datasets, while also enabling process auditing, towards reproducible and repeatable analyses of ORG data.
The software page can be found <a className="text-primary-400 underline" target="_blank" href="https://pypi.org/project/f-cell/">[here]</a> and doi: 10.1167/tvst.15.3.23 <a className="text-primary-400 underline" target="_blank" href="https://pubmed.ncbi.nlm.nih.gov/41873902/">[here]</a>.
