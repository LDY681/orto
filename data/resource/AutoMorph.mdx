AutoMorph is a full automated tool that consists of four modules: image preprocessing, image quality grading, anatomical segmentation, and metric measurement.
Source code for this pipeline is available from <a className="text-primary-400 underline" target="_blank" href="https://github.com/rmaphoh/AutoMorph">[here]</a>.
