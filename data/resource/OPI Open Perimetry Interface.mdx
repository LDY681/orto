The OPI is a standard for interfacing with visual field testing machines (perimeters) first started as an open source project with support of Haag-Streit in 2010.
It specifies basic functions that allow many visual field tests to be constructed.
As of February 2022 it is fully implemented on the Haag-Streit Octopus 900 and 'CrewT ImoVifa' ('Topcon Tempo') with partial implementations on the Centervue Compass, Kowa AP 7000 and Android phones.
It also has a cousin: the R package 'visualFields', which has tools for analysing and manipulating visual field data.
For more information about OPI go to: McKendrick AM. Et al. Response times across the visual field: Empirical observations and application to threshold determination.
Vision Res. 2014, 101:1-10 <a className="text-primary-400 underline" target="_blank" href="https://doi.org/10.1016/j.visres.2014.04.013">[here]</a>.
