OCTAVA – a software tool developed by our group for optical coherence tomography angiography (OCTA) image analysis.
The software delivers microvascular metrics, including vessel area density, vessel length density, vessel diameter, fractal dimension, vessel tortuosity, branchpoint density and foveal avascular zone (FAZ) metrics,
including FAZ area, FAZ perimeter, FAZ axis ratio, FAZ circularity, FAZ acircularity index, and FD-300.
For more information on how to use the tool, go to the OCTAVA website [here],
read the following peer-reviewed papers: <a className="text-primary-400 underline" target="_blank" href="https://www.nature.com/articles/s41598-024-53501-6">[here]</a>
and Untracht GR, et al. OCTAVA: An open-source toolbox for quantitative analysis of optical coherence tomography angiography images. PLoS One. 2021 <a className="text-primary-400 underline" target="_blank" href="https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0261052">[here]</a>.
Download the MATLAB app and the source code on GitHub <a className="text-primary-400 underline" target="_blank" href="https://github.com/GUntracht/OCTAVA">[here]</a>,
or a stand-alone version <a className="text-primary-400 underline" target="_blank" href="https://sourceforge.net/projects/octava/files/">[here]</a>.
